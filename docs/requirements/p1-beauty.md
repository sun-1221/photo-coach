# 自然上镜 v1

Scope：ApprovedSeparate；2026-09-03 用户批准执行。最高入口：[requirement.md](../requirement.md)。不是对全部局部颜色处理或 P0 的批准。

- 当前后摄单人标准 Photo，默认 OFF。创意菜单主动选择 NATURAL / SOFT，重置回 OFF。开启前说明复用本机关键点、不上传、原片优先、效果需另存及预览近似。与 Live、扩展模式冲突时拒绝本次选择并提示先关闭，不默默切换。
- 仅平滑脸颊、额头、下巴纹理，软边融合并排除眼眉、鼻部、嘴部。不做肤色分类、瘦脸、大眼、美白、妆容、情绪/身份/外貌推断、LUT、私有 API 或生成重绘。Face 快照仅内存，不保存坐标、帧或身份。
- 缺关键点、多人、侧脸（初始 |yaw| > 35°）、时间戳/变换无效时退到零；150ms 后衰减，300ms 完全退出。NATURAL 融合 0.18 / 细节保留 0.70；SOFT 0.28 / 0.60。均为待校准初值，无滑杆。任何状态不锁快门或阻断口令。
- 热策略暂停非必要预览时也暂停美颜并说明；效果错误可见回退标准预览。关闭时不绑定效果。原图发布先于成片检测/美颜，捕获固定预设与引擎版本，重试与另存用对应快照。
- 默认只原片和私有配方，明确另存或 ORIGINAL_AND_EFFECT 才生成独立 SDR JPEG。在有界解码后的拍摄图重新检测，异常报可恢复失败；无有效单人时不应用美颜并给说明。旧配方/日志缺字段按 OFF；未知引擎不冒充已执行。
- 保持原有风格/七项编辑。拍后原图对比仍为真原图；拍后未渲染美颜的预览明确提示“美颜将在另存时应用”。P-1 对照实验关闭美颜。遮挡、胡须、眼镜、发丝、肤色、光照及镜头/画幅需专项校准，不声称准确肤色保护。

FR/UX 唯一定义见[矩阵](../traceability/requirements-matrix.md)和[验收](../acceptance/acceptance-plan.md)。真实效果、性能与目标机验收均为 NotRun。
