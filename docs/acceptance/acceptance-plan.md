## 2.2 本轮修订的验收证据要求（2026-09-05）

上述修改是目标验收合同，UX-04/06/27/30/33/34 的新增分支未执行，保持 NotRun。历史测试结果仅证明原覆盖，不自动继承为修订后通过。UX-15 的分母和比例已于 2026-09-12 按用户裁决统一为整个屏幕高度的五分之一；修订后目标机验证 NotRun。

P-1 实验按需求总纲第 3.2、3.3.1 节执行：采样前冻结配置与待决计算规则；用含超时、主动退出、失败、缺评、失访和重复恢复的示例记录复算指标；研究侧核对会话关联、导出责任和保留/删除期限。冻结前不得开始可用于 Go 的正式采样，示例复算不能替代用户实验。

口令覆盖验收按意图 × 启用场景 × 听众及安全回退检查，每条稳定 ID 对应触发、退出、失效和未知输入样例；数量由覆盖推导，保留历史样张，不按数量配额删减行为。

### 9.3 质量门槛

本轮自动化结果（2026-08-31）：`coach:test` Pass、`androidApp:testDebugUnitTest` Pass、ExplainApi .NET 3/3 Pass。该结果不改变本文件任何 instrumented/小米 14 Pro/HyperOS `NotRun`。

- 本地自动化门禁依次运行 `.\gradlew.bat :coach:test` 与 `.\gradlew.bat :androidApp:testDebugUnitTest`；前者覆盖口令安全边界与多人回退，后者覆盖脸框亮度的旋转/裁剪/样本边界、HD→SD 会话顺序、普通 SDR JPEG 选择及 Motion Photo XMP 替换/回退。命令通过只代表 JVM 覆盖，不替代第 9.2 节真机矩阵。
- 第 3.3 节产品指标全部保留原始数据。
- 同机同景与系统相机比较，教练照片不能稳定出现明显更暗、更噪或更糊。
- 扩展模式无法与分析同时工作时，保留分析并回退标准拍照，界面不可黑屏。
- 五秒内出现方向相反提示、重复 TTS、两个动作同屏、快门被指导锁住，均为 P-1 阻断问题。
- 未完成第 3.2 节三组对照实验，不能以内部主观样片代替 Go 决策。
- P1 姿势验收样本中，可观察口令触发精度目标为 ≥90%，改善后的退出响应 p95 ≤1 秒；低置信度和多人样本不得出现单人姿势。样本不足或未记录设备身份时保持 NotRun。
- P1 风格推荐必须稳定、可解释且原图第一；真实颜色、人像保守强度和推荐偏好未经受控样张与人工盲评不得标为 Pass。
